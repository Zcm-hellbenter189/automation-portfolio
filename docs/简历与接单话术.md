# 简历与接单话术

> 三个作品的对外包装指南：怎么写进简历、怎么写接单介绍、面试/接单高频问题怎么答。
> 核心逻辑：**你卖的不是"会用工具"，而是"能交付、能验收、有文档、懂合规的可靠自动化服务"**——这正是测试背景给你的差异化。

## 一、简历项目经历写法

简历项目经历推荐用「背景 → 动作 → 结果」结构，每段 3-4 行，突出量化与工程化。

### 作品 1：接口自动化测试框架

> **自动化测试框架设计（独立项目）**
> 基于 Python + Requests + Pytest 设计并实现企业级接口自动化框架，支持数据驱动、多环境切换（dev/test/prod）与接口依赖传递（变量池）；封装 HTTP 客户端实现鉴权注入、超时控制与指数退避重试，统一断言库覆盖状态码、业务码、字段类型与响应耗时校验；集成 pytest-html 报告与一键运行脚本，实现「clone 即跑」。
> **成果**：15+ 用例覆盖登录鉴权、用户 CRUD、业务异常与性能场景，全部通过；报告一键生成。

### 作品 2：合规爬虫

> **合规数据采集系统（独立项目）**
> 使用 requests + parsel 实现公开图书榜单数据采集，覆盖请求限速、指数退避重试、robots.txt 合规校验、字段清洗去重、CSV/SQLite 双存储与 Excel 报表导出全链路；具备「遇 403/429 即停」的合规意识与断点续爬的稳定性设计，目标站点全配置化可快速适配。
> **成果**：单次采集 250+ 条结构化数据（书名/作者/评分/评价数），自动生成带评分分布的 Excel 报表。

### 作品 3：RPA 定时监控

> **RPA 定时监控系统（独立项目）**
> 实现「采集 → 判定 → 报表 → 告警」自动化闭环：requests 采集多目标状态码与响应耗时，基于阈值与环比波动规则自动判定异常；openpyxl 生成概览/明细/告警三页 Excel 报表，SQLite 持久化历史采样；APScheduler 实现 Windows 下跨平台定时调度，告警支持日志与可选 SMTP 邮件。
> **成果**：3 目标定时监控，异常识别与报表生成全自动，可接入真实业务站点。

### 简历通用技巧

- 项目经历放在技能清单之后、教育背景之前（面试官先看你会做什么）
- 每个项目配 GitHub 链接 + 一句"可运行演示"
- 主动写"合规""可复用""配置化"这些词——接单客户和面试官都吃这套
- 数字比形容词有用：15+ 用例 / 250+ 条 / 3 目标 / 3s 响应告警

## 三、面试 / 接单高频问题与回答要点

**Q：接口自动化里，接口之间有依赖怎么处理？**
A：用变量池（线程安全的共享容器）做响应提取与传递——登录后把 token、user_id 存进变量池，下游用例直接取用；配合 fixture 的 session 级作用域保证一次登录全局复用。我的框架里 core/extractor.py 就是干这个的。

**Q：爬虫被反爬（403/429）了怎么办？**
A：分三层看：一是合规层——先查 robots.txt，遵守限速，不做对抗；二是工程层——指数退避重试、UA 轮换、限速器，把请求频率压到站点可接受范围；三是原则——绝不绕验证码、不批量换 IP 硬刚，遇到强反爬就停下并跟客户说明，评估换合规数据源。

**Q：为什么自动化项目里要强调合规？**
A：合规直接决定项目能不能长期做、会不会给客户带来法律风险。爬虫红线主要是：不碰隐私/登录态、遵守 robots.txt、限速、不绕反爬、数据不商用转售。把合规做进代码（比如启动前强制校验 robots.txt），既是自我保护，也是给客户的信任背书。

**Q：Windows 下定时任务怎么做？**
A：首选 APScheduler（纯 Python，代码内配置 cron/interval，跨平台）；如果要系统级自启，用 Windows 任务计划程序（触发器选"计算机启动时"，程序指向 pythonw.exe，无黑窗口）。不需要 cron。

**Q：生成的 Excel 报表中文乱码？**
A：CSV 用 utf-8-sig 编码写（Excel 双击直接打开不乱码）；如果抓回来的网页文本乱码，是响应解码问题——对未声明 charset 的响应用 UTF-8 兜底解码（requests 默认 latin-1 是个坑）。

**Q：你的项目能在线演示吗？**
A：可以。三个项目都自带本地 Mock 数据源（纯标准库实现），clone 下来装依赖就能跑，不需要外网和付费服务。面试/谈单时可以现场演示。
